# 🎓 Cartão Digital Acadêmico

Aplicação desenvolvida utilizando o framework Ionic com o objetivo de criar um cartão digital de identificação acadêmica, acessível via navegador.

---

## 📱 Funcionalidades

- Exibição de informações do aluno:
  - Nome completo
  - Matrícula
  - Turma
  - Campus
- Foto de perfil
- Logo da instituição
- Navegação entre telas
- Tela "Sobre" com descrição pessoal
- Interface moderna e responsiva
- Botão com animação, efeito de clique e loading

---

## 🛠️ Tecnologias utilizadas

- Ionic Framework
- Angular
- HTML5
- SCSS
- TypeScript
